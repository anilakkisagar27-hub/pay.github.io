
# Pay Parking System

## How to Run

### Backend:
1. Navigate to the backend folder.
2. Compile and run the Java file:
   ```
   javac PayParkingSystem.java
   java PayParkingSystem
   ```

### Frontend:
1. Open `frontend/index.html` in any browser.
2. Ensure `back.png` is placed in the same folder for background.
